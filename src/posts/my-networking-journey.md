# 🌐 My Networking Journey — From Fundamentals to Practical Experience

I started learning computer networking from the fundamentals and gradually moved toward practical configuration and troubleshooting.

### 📚 1. Networking Fundamentals
- Network types and topologies
- OSI & TCP/IP models
- Network devices
- Transmission media
- Ethernet and RJ45

### 🔢 2. IPv4 Addressing
- IPv4 structure
- Network vs host portions
- Subnet masks
- Public & private IPv4
- Loopback and link-local addresses
- Classful vs classless addressing (CIDR)

### 🔀 3. Routing & Network Communication
- Default gateways
- Routing concepts
- Routing to the Internet
- NAT (Network Address Translation)
- Broadcast and directed broadcast
- Understanding how packets move between networks

### 🔧 4. Cisco Configuration
- Cisco IOS basics
- Switch configuration
- VLANs & Access ports
- Trunk concepts
- Router configuration
- Basic network troubleshooting

### 🖥️ 5. Cisco Packet Tracer
I moved from theory to practice by creating and configuring network topologies, connecting devices, assigning IP addresses, configuring VLANs and testing connectivity.

### 🧪 6. Real Troubleshooting Practice
I also practiced using Windows networking commands such as:

```powershell
ipconfig
ping
```
and connectivity testing between local gateways and Internet addresses.

### 🎓 7. Certification & Continuous Learning
This journey has included Cisco networking coursework, practical Packet Tracer exercises, networking training, and certification-focused learning.

The biggest lesson has been that networking is not only about memorizing commands — it is about understanding **how devices, addresses, routes and packets work together.**

Still learning. Still practicing. 🌐🚀
